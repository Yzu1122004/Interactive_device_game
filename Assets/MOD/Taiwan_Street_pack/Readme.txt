By default the asset uses Universal render pipeline.
Before you start, please follow the steps below:

### Built-in render pipeline ###
1. Set the color space to Linear
Edit > Project Settings > Player > Other Settings > Rendering - Color Space > Linear
2. Unpack the package named "Built-in" from the "Settings" folder.


### Universal render pipeline ###
1. Set the color space to Linear:
Edit > Project Settings > Player > Other Settings > Rendering - Color Space > Linear
2. Set your Universal Render Pipeline Asset:
Edit > Project Settings > Graphics > Scriptable Render Pipeline Settings
3. Unpack the package named "URP" from the "Settings" folder.


#### Switching back to Built-in render pipeline ###
1. Remove Universal Render Pipeline Asset:
Edit > Project Settings > Graphics > Scriptable Render Pipeline Settings
2. Unpack the package named "Built-in" from the "Settings" folder.
